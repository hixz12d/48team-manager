Sub2API 推送 / 状态

同机容器直连用 http://sub2api-canary:8080。8101 只绑宿主机回环，容器里不要填 host.docker.internal:8101。

没有 Admin API Key 时，状态读取和推送都会用这对账号登录。

推子号时套这个 Sub2API 账号创建模板。模板默认不带代理，代理按母号 ISP 自动匹配。

模板没带分组时的兜底。当前 Team轮转模板会覆盖这个值。

免费号推送套这个模板。当前线上是 Free模板，进 GPT Luna 线路。

席位页注册免费号时，表单没填代理就用这个。

Cloudflare 邮箱读码

兼容 icloud-hme 的 GET /admin/mails。子号只填 Hide My Email 别名，例如 afraid-16.scepter@icloud.com。

iCloud HME

容器内用 http://icloud-hme:8081。本机调试可改成 http://127.0.0.1:8081。

默认打 Team 名称；名称为空时用这里的映射，再空用母号邮箱 local-part。不要用 Team#3。

探测会列出未占用别名数量。领号走 HME，读码仍走 Cloudflare。
