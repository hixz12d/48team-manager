设计具体性：保留原有控制台颜色、侧栏和原生表单；服务配置、自动化范围、手机号租约均对应本产品任务，没有增加通用装饰模块。阅读顺序为服务配置与自动化并行，后台密码独立放在最后。风险动作仍走原有确认。

认知负担：中等。自动化范围、额度说明与轮转策略同时展开，超过一次决策需要的信息；专业操作员可以直接修改字段，新手仍需理解多个术语。保存反馈由“滚动找按钮”变为始终可见，失败不会清空输入，减少不确定性。

优点：分组和单位恢复；修改可见且可撤销；授权与危险动作颜色区分。
