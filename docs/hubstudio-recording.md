# 记录一次 HubStudio 手动全流程

目标：由用户按平时方式完成「移除旧子号 → 邀请新邮箱 → 无痕注册 → 入组 → OAuth」，助手只观察并对照时间线。记录不能揭示服务端风控原因，也不保证复现相同验证结果。

## 用户需要做什么

1. 打开要使用的 HubStudio 母号环境，停在官网成员管理页，先不移除成员。告诉助手团队名称及这次要使用的环境；如果注册用另一套环境，也提前说明。
2. 助手核对当前本机调试端口，启动监听，并确认目标页已连接。期间不要重启该环境，端口会变化。
3. 可同时用 Windows 截图工具的录像功能，或 OBS 的窗口采集录制浏览器。若录像工具不能覆盖切换后的无痕窗口，调整录制区域覆盖目标窗口。录像保持在本机；密码显示、验证码、完整授权地址或回调地址可能进入录像，分享前应剪裁或遮挡。
4. 用户照平时习惯手动踢人、邀请；保留邀请角色、席位选择和成功结果的画面。只需要在聊天里告知「邀请完成」「开始注册」「准备授权」等节点，助手负责给时间线标注阶段。
5. 按平常成功流程操作无痕注册和原版插件，不为配合记录临时改变邀请/注册顺序或等待时间。遇到需要补点、换标签页、切换空间、验证码重发时照实操作，说明发生了什么。
6. 完成OAuth或遇到手机号页后停止记录，保留账号。通过时间线与录像共同回看，不直接凭一次结果认定风控原因。

同一环境的多个无痕窗口共享会话。是否先关闭旧无痕窗口应与要对照的实际流程一致；开始前记下有无旧无痕会话，不让记录工具擅自清理Cookie或关闭窗口。

## 记录工具

`scripts/hubstudio_record.py`，使用项目已有Python环境及websockets。页面观察脚本为 `scripts/hubstudio_flow_observer.js`。不改原版注册扩展、不启动浏览器、不操作账户，不自动填写、点击、提交或发起业务请求。

限定指定的本机CDP端口，对该浏览器中ChatGPT/OpenAI登录页面及指定Team48扩展后台进行观察。普通窗口和无痕窗口均可能被包含；记录前应避免在同一环境中操作其它OpenAI账号。其它站点不收集页面操作。同一浏览器上下文以匿名编号关联，插件后台额外记录原生incognito布尔值。

可记录：

- 已知按钮类别（移除、邀请、继续、确认、Owner、Premium等）、输入框获得焦点的类别、表单提交事件；不记录输入内容或按键。
- 页面类型、对话框是否显示、聊天输入框是否出现、手机号标题是否出现。未知按钮统一记other，不保存任意页面文字。
- 相关浏览器请求的方法、接口类别、HTTP状态、相对耗时，以及跳转顺序。成员ID、工作空间ID、邮箱及所有URL查询参数/片段不保存。
- 原版插件的运行模式、阶段、收码/提交/暂停/完成等允许的事件。可以区分注册完成与后续授权手机号要求。插件旧任务可能在连接时出现，用run_started_epoch_ms区分；插件最多保留200条事件，溢出会记录truncated。
- 操作人员标注的阶段和本机UTC时间。

不会生成原始HAR，不调用getResponseBody/getRequestPostData，不读取Cookie接口，不落盘请求头、请求/响应正文、密码、验证码、令牌、授权code或完整URL。CDP事件本身可能携带原始字段，工具只提取白名单元数据，其余字段不输出或写文件。扩展诊断在浏览器内转换成允许字段后才返回。

## 启停（助手通常代为执行）

以下PowerShell命令在项目根目录运行，端口需要每次重新识别，示例不能当固定值。输出目录必须不存在，防止覆盖之前的记录。

```powershell
$recordPort = 49328  # 替换为本次核实的端口
$recordDir = "dist/hubstudio-record-$(Get-Date -Format yyyyMMdd-HHmmss)"
.\.venv\Scripts\python.exe scripts/hubstudio_record.py record --port $recordPort --out $recordDir
```

母号管理和子号注册使用两个浏览器进程时，可重复传 `--port`。如果担心页面监听影响时序，可加 `--no-dom`，只观察网络元数据和原插件诊断，配合录像；此模式没有点击/焦点/表单事件。

助手应等 `timeline.jsonl` 出现对应页面的attached/navigation记录再告知用户开始；控制台显示Recording只表示记录进程已启动，不代表所有页面已接通。启动和过程中遇到observer_error应说明记录缺口。

另一终端标注阶段或停止（替换为本次实际输出目录，不依赖上一终端变量）：

```powershell
.\.venv\Scripts\python.exe scripts/hubstudio_record.py mark --out dist/hubstudio-record-本次时间 --stage invite
.\.venv\Scripts\python.exe scripts/hubstudio_record.py stop --out dist/hubstudio-record-本次时间
```

阶段：prepare、remove、invite、register、oauth、phone、done。默认最多录制1小时，可用 `--seconds` 调整（最多4小时）；Ctrl+C也会收尾。正常停止会移除观察脚本和事件监听并断开调试连接，不关闭浏览器或页面。不要用强制结束进程代替正常停止；强杀可能来不及移除页面观察器，重新加载相关页面可清除旧文档的监听。

输出：

- `timeline.jsonl`：边录边保存的脱敏时间线，每行一个事件。
- `summary.json`：停止后的数量、时长、错误汇总。没有此文件可能仍在运行或异常中断。
- `stage.txt` / `STOP`：本次记录的阶段、停止控制文件。

## 能力边界

- 这是客户端观察记录，不是无损录制或完整请求回放。新标签页约每0.5秒发现一次，接入前发生的请求可能漏记；断连不自动刷新或重做操作，插件自身也可能截断旧事件。
- 网络200不代表业务邀请一定成功，需结合界面成功提示及后续官方成员回读。这里不保存邀请payload，因此无法单靠记录比较完整请求参数；如确需比较，应后续单独限定范围提取角色/席位等非秘密字段。
- CDP连接、少量观察代码和轮询本身有开销；不能承诺与完全不监听时毫无差异。脚本不阻止事件、不打断点、不拦截或改写请求。isTrusted仅是浏览器事件属性，不能据此断定是人还是自动化点击。
- 观察器不会跟踪另一个未指定浏览器进程，也不会记录手机或其它设备操作。团队管理工具从服务器发起的请求不在本机浏览器监听范围内；用户在官网手动踢拉才能看到对应浏览器请求。
- 不要为了记录而重复踢拉或新增账号；真实操作仍按用户当次授权执行。
