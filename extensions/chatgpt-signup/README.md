# ChatGPT 注册助手 · 自用版 0.11.0

支持两种用法：**批量注册**（在普通窗口打开插件，粘贴多行邮箱一键自动轮换无痕窗口逐个注册）与 **单次注册**（在无痕窗口打开插件，输入单个邮箱点击开始注册）。读信配置（icloud-hme 服务 token 与账号编号，或 Cloudflare 收件箱）和默认注册资料已内置在 `private-config.mjs`，不需要配对码、后台登录或保存设置。

## 做什么 / 不做什么

- 做：在 ChatGPT 网页自动完成注册（邮箱、密码、验证码、姓名、年龄/生日），通过 `chrome.debugger`（CDP）由浏览器生成键鼠输入；按收件别名精确匹配读取 OpenAI 的新验证码；配置 Team48 令牌后，默认**直接授权接入 `codex-rs`（不查 Team48 团队）**，也可下拉切回查 Team48 团队接入；批量模式自动逐个新建干净无痕窗口、完成后关闭清 Cookie 并随机冷却再跑下一个。
- 读信来源：打包时带了 icloud-hme 配置就经 `https://hme.xiaozhudf2026.foo/api/inbox` 从 iCloud 邮箱读（该 HME 账号须已填 App 专用密码；同时查收件箱、垃圾箱和「已删除」）；没带就读 Cloudflare 收件箱。服务器模式始终用 Cloudflare。
- 手机验证（注册和 Codex 授权阶段都算）：默认的「直接授权接入 rs」不启用自动接码，遇到手机验证直接暂停交人工处理（批量模式保留当前窗口并响提示音）。切换到「查 Team48 团队并接入」或指定团队接入时，仍从 Team48 号码池领 +1 号自动接码（最多换 3 个号）。
- 不做：不创建邮箱或 HME 别名、不发团队邀请、不写 iCloud；不接入或授权母号；不保存或导出 ChatGPT 令牌；不绕过或自动点击人机验证；日志不上传。输入的邮箱必须是该 HME 账号下的别名（或已能转发到内置 Cloudflare 收件箱）。
- 人机验证、限流、网页报错或未识别页面会暂停并说明原因，处理后点「继续」。没带 Team48 令牌、两种手工模式或项目内托管注册遇到手机验证仍会暂停，需人工完成。
- 项目内托管注册复用本插件 `content.js`，见项目 `docs/ARCHITECTURE.md`。
- 服务器模式由 Team48 自动使用，本机无需设置。

## 安装 / 更新

1. 解压自用包，用其中 `chatgpt-signup` 文件夹覆盖原插件目录；首次安装则在 `chrome://extensions` 打开开发者模式，加载该文件夹。不要同时加载多个版本目录。
2. 在 `chrome://extensions` 点插件的「重新加载」，并确认插件详情里的「允许在无痕模式下运行」已开启（批量模式和单次无痕注册都需要此权限）。
3. 关闭旧的注册标签页和其他无痕窗口，再开始新任务。
4. 确认插件弹窗（以及未隐藏的网页进度卡片）显示 **0.11.0**。

新版默认「直接授权接入 rs」需要服务端 `/api/ext/ping` 声明 `rs_direct=true`。先上线配套 48team 后再加载新版；该模式不查 Team48 团队、不同步母号、不依赖母号代理（换票和首次导入直接从 `codex-rs` 挑启用且健康、挂号最少的代理；`rs` 里已存在同邮箱时按身份覆盖更新凭据并保留原有分组、代理和并发设置）。切回查团队接入时仍要求 `proxy_policy=workspace_owner` 并沿用母号代理。

HubStudio（ChroBrowser）：在该环境的 `chrome://extensions` → 本插件详情 → 开启「允许在无痕模式下运行」。批量注册直接在普通窗口点插件图标即可；单次注册按 `Ctrl+Shift+N` 在无痕窗口使用插件。

推荐在环境「启动参数」里加上（多开时被遮挡的窗口不降速，并隐藏「正在调试此浏览器」提示条）：

```
--disable-backgrounding-occluded-windows --disable-renderer-backgrounding --disable-background-timer-throttling --silent-debugger-extension-api
```

## 批量无痕注册

1. **准备工作**：确认插件已开启「允许在无痕模式下运行」，并**先关闭当前所有已打开的无痕窗口**（保证每个号都在全新干净的无痕环境里运行）。
2. **发起批量任务**：在**普通窗口**点击插件图标，默认进入「批量注册」页签：
   - 在多行输入框中粘贴邮箱列表（每行一个，单批最多 **50** 个，自动去重并实时校验格式）。
   - 按需选择「注册完成后自动接入团队」（与单次模式一致，支持自动识别邀请团队 / 指定团队 / 不自动接入）和「隐藏网页进度卡片」。
   - 点击「开始批量注册」，插件会在普通窗口自动挂起常驻进度标签页（`popup.html?tab=1`），并在新开的无痕窗口中逐个执行注册与团队接入；每跑完 1 个号自动关闭无痕窗口，随机冷却 3～8 秒后再开下一个。
3. **中途异常与人工介入**：
   - 遇到真人验证框、需人工处理的手机验证或网页限流时，队列会自动暂停、保留当前无痕窗口，进度页高亮提醒并播放提示音。点「查看无痕窗口」处理完成后点「我已处理，继续」，或点「跳过此号，跑下一个」/「停止整批」。
   - 遇到收不到邮件验证码、查不到团队邀请、多团队冲突或单步超时等单号问题时，插件自动记录失败原因、关闭该无痕窗口并继续跑下一个号。
4. **导出账号密码与重跑**：
   - 运行中和结束后均可随时点击：**「复制成功账号密码」**（每行 `邮箱----密码`）、**「复制成功邮箱」**、**「复制失败/未跑邮箱」**（可直接粘回重跑）。
   - 明细列表中只要某个号已生成密码（包括设完密码后在授权阶段失败的号），行右侧均提供单独的「复制账密」按钮，避免丢密码。
   - 本批记录与密码仅暂存在浏览器内存（`chrome.storage.session`），关闭整个浏览器后自动清除，请及时复制保存；跑完后点「清空本批记录，开始新批次」即可开始下一批。

## 操作模式（单次注册）

| 模式 | 行为 | 时限 |
| --- | --- | --- |
| 自动填写并提交（默认） | 自动填写和点击；检测到你手工改字段时暂停。 | 10 分钟 |
| 自动填写，手动提交 | 每步填好后等你点网页按钮。 | 30 分钟 |
| 手工填写，确认后由插件提交 | 不填写、不取邮件；你填好后点进度卡片「已填好，提交本步」。 | 30 分钟 |
| 全程手工，仅记录流程 | 不填写、不点击、不取邮件，只观察步骤和最终登录状态。 | 30 分钟 |

- 自动模式可展开「注册资料」指定姓名与生日，留空则随机；可勾选隐藏网页进度卡片，在弹窗中暂停/继续/停止。
- 暂停和刷新会保留任务；不要在注册中途切换模式。暂停时可用「刷新网页并继续」。
- 完成后可复制脱敏诊断记录（不含邮箱、密码、验证码、Cookie、令牌或页面原文）。

## 授权接入（可选）

打包时带上 Team48 令牌后，弹窗出现「注册完成后自动接入」，默认选 **「直接授权接入 rs（不查团队，推荐）」**：
- 全程不查 Team48 团队、不触发团队同步、不建 Team48 本地账号档案、不记今日切换次数（邀请该邮箱的 Team 不在 Team48 里也能用）。
- 网页遇到接受邀请或工作空间选择（`Choose a workspace`）时，自动排除 `Personal` / `个人账户`：**只有 1 个 Team 自动点选**；**检测到 2 个及以上 Team 或只有个人空间时立即停止**（批量模式自动记失败跳过跑下一个）。
- 注册完成后在同一无痕标签页打开桌面版 Codex 授权链接，拦截 `127.0.0.1:1455` / `localhost:1455` 回调交给 48team 经 `codex-rs` 代理换取令牌、校验 Team 工作空间套餐后直接写入 `codex-rs`（新号沿用 48team 设置页的 `codex-rs` 首次导入默认参数；`rs` 已有同邮箱账号时覆盖更新凭据并保留原有分组、代理、并发和权重）。遇到手机验证时暂停交人工处理。
- 下拉框仍保留「查 Team48 团队并接入」和指定团队接入备用（走原同步 → 接入本地 → 母号代理 → 按全局设置推送 → 计数流程）。

插件调用 `/api/ext` 下接口：`GET /ping`、`POST /rs/start`、`POST /rs/complete`、`GET /workspaces`、`POST /resolve`、`POST /handoff`、`POST /handoff/complete`、`POST /phone`（团队模式手机验证接码）。令牌不能读取账号凭据或接码链接，也不能删除或邀请成员；不要外传自用包。

开启方法：

1. 生成令牌：`python -c "import secrets; print(secrets.token_urlsafe(32))"`。
2. 服务器 `/opt/team48/.env` 写入 `EXTENSION_API_TOKEN=<令牌>`（至少 24 位，否则 `/api/ext/*` 一律 404），然后在 `/opt/team48` 重建：

   ```bash
   docker compose -p team48 -f deploy/docker-compose.yml up -d --build --no-deps team48
   ```

3. 本机打包时加 `--team48-token <令牌>`（见下节），再到 `chrome://extensions` 重新加载；浏览器可能要求确认新增权限。

## 打包

```powershell
python scripts/build_signup_extension.py --local-config --unpack
```

- 用本机已有的 `private-config.mjs` 生成 ZIP 并更新 `dist/chatgpt-signup`，不连接 VPS。
- 首次没有本机配置时，不带 `--local-config` 运行：只读 VPS 上既有的 Cloudflare 配置，不修改或部署服务器。
- `--team48-token <令牌>` 写入 Team48 令牌（之后用 `--local-config` 重打包会保留）；`--no-team48` 移除令牌。
- `--hme-token <ICLOUD_HME_SERVICE_TOKEN> --hme-account <acc_...>` 改为从 iCloud 读验证码（之后重打包会保留）；`--no-hme` 移除，改回 Cloudflare。
- 配置文件和自用 ZIP 不进入 Git。

## 常见问题

| 现象 | 处理 |
| --- | --- |
| 弹窗版本号不是 0.11.0 | 确认覆盖的是正确目录，重新加载插件，关闭旧注册页。 |
| 无痕窗口里没有插件或提示需开无痕权限 | 到 `chrome://extensions` 本插件详情里开启「允许在无痕模式下运行」。 |
| 批量启动提示已有打开的无痕窗口 | 先关闭浏览器里所有已开的无痕窗口，再点「开始批量注册」。 |
| 多开时窗口卡住、按钮等不到 | 加上面的 HubStudio 启动参数；未提交前的等待类暂停会自动重试。 |
| 页面顶部出现「正在调试此浏览器」 | 加 `--silent-debugger-extension-api`；点提示条取消会暂停任务。 |
| 一直等验证码 | 确认输入的是该 HME 账号下的别名，且 HME 账号页已填 App 专用密码；120 秒没新邮件会暂停，在网页点重新发送后继续。 |
| 提示「iCloud HME 账号未配置 App 专用密码」 | 到 HME 账号页给该账号填 App 专用密码（用户名是 @icloud.com 地址）。 |
| 自动接入返回 404 | 服务器未设置 `EXTENSION_API_TOKEN`、不足 24 位，或服务器版本过旧。 |
| 提示「号码池没有可用号」 | 到 Team48「资源 → 手机号」导入 +1 号码（`+1xxxxxxxxxx----接码链接`），再点继续。 |
| 提示「已连续 3 个号失败」 | 多半是账号或代理被风控，先人工检查；点继续只会再试 1 个号。 |
| 提示页面脚本与后台版本不一致 | 刷新注册网页。 |
